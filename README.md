## Learning Progress

### Lesson 1: What is GitHub?

- GitHub is a platform for managing and collaborating on projects.
- A Repository is the basic unit used to organize and manage a project on GitHub.
- A README explains what a project is and how to use it.
- A LICENSE explains how others are allowed to use the project.
- A Repository can contain files, folders, code, documentation, and version history.
